Use these commands to quickly start study sessions with Claude.

## 🎯 Interview Preparation

```
"Let's start Sprint Day 1"
"Continue with Sprint Day 2"
"Time for Sprint Day 3"
"Quiz me on Sprint Day [1/2/3] questions"
```

## 🎯 Pro Tips

### Be Specific
✅ "Let's practice the flash sale design from Sprint Day 3"
❌ "Let's practice system design"

### Ask for Interaction
✅ "Quiz me on Day 2 questions and give me feedback"
❌ "What are the Day 2 questions?"

### Request Depth
✅ "Explain CQRS with code examples and when to use it"
❌ "What is CQRS?"

### Combine Commands
```
"Let's start Sprint Day 2. First explain Next.js concepts,
then quiz me on the practice questions, and finally do a
code review exercise."
```

## 🔄 Session Flow Examples

### Efficient Study Session
```
1. "Start Sprint Day 1, Hour 1"
2. [Study the content]
3. "Quiz me on the practice questions"
4. [Answer questions, get feedback]
5. "Do the interactive exercise"
6. [Practice with Claude's guidance]
7. "Summarize what I learned today"
```

### Deep Dive Session
```
1. "Begin Deep Dive Day 3, Session 1"
2. [Learn NestJS patterns]
3. "Show me the code examples"
4. [Review implementations]
5. "Let me implement the ProductsService"
6. [Code with Claude's guidance]
7. "Review my implementation"
8. [Get feedback and improvements]
```

Claude will:
- ✅ Guide you through interactive exercises
